Python card

The library calls these notes actually use, in one place. Nothing here is introduced for the first time; each row links to the unit that explains what the call is for and what it does when the data are not what you assumed.

Everything below assumes the standard imports:

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from scipy import stats
