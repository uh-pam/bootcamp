Idea · 6 min

Vectors: adding and scaling

★ essentialMP

A vector is an ordered list of numbers, its components. We write vectors in bold:

x=(x1,x2,…,xn)\mathbf{x} = (x_1, x_2, \dots, x_n)x=(x1​,x2​,…,xn​)

A column of 333 penguin masses is a vector with n=333n = 333n=333 components. A vector with two components can be drawn as an arrow.

Two operations work component by component, exactly as a NumPy array does (a plain Python list does not: / 10 fails and * 2 repeats it):

  • Adding two vectors of the same length: (u1,u2)+(v1,v2)=(u1+v1,  u2+v2)(u_1, u_2) + (v_1, v_2) = (u_1 + v_1,\; u_2 + v_2)(u1​,u2​)+(v1​,v2​)=(u1​+v1​,u2​+v2​)
  • Scaling by a number ccc: c (u1,u2)=(c u1,  c u2)c\,(u_1, u_2) = (c\,u_1,\; c\,u_2)c(u1​,u2​)=(cu1​,cu2​)
The same sum, three ways

The dot product

★ essentialMP

One more operation, the most useful one in data science. Picture a shopping basket:

VectorApplesBreadCheese
Price (£) p\mathbf{p}p1.200.802.50
Quantity q\mathbf{q}q352

The total cost multiplies each pair and adds the results:

1.20×3+0.80×5+2.50×2=3.60+4.00+5.00=12.601.20 \times 3 + 0.80 \times 5 + 2.50 \times 2 = 3.60 + 4.00 + 5.00 = 12.601.20×3+0.80×5+2.50×2=3.60+4.00+5.00=12.60

That is the dot product of the two vectors:

u⋅v=u1v1+u2v2+⋯+unvn\mathbf{u} \cdot \mathbf{v} = u_1 v_1 + u_2 v_2 + \dots + u_n v_nu⋅v=u1​v1​+u2​v2​+⋯+un​vn​

The result is a single number, not a vector. In NumPy, write @:

Work out (3,0,2)⋅(1,5,4)(3, 0, 2) \cdot (1, 5, 4)(3,0,2)⋅(1,5,4) by hand.

You added each pair, (3+1)+(0+5)+(2+4)(3+1) + (0+5) + (2+4)(3+1)+(0+5)+(2+4). A dot product multiplies each pair, then adds.
