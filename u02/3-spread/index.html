Spread as a length

The square root brings the variance back to the data’s units (minutes, grams). The SD is the typical distance of a value from the mean.

Worked example: the SD of (2, 4, 4, 6) by hand
  1. Mean: xˉ=(2+4+4+6)/4=4\bar{x} = (2 + 4 + 4 + 6)/4 = 4xˉ=(2+4+4+6)/4=4.
  2. Deviations: d=(−2,0,0,2)\mathbf{d} = (-2, 0, 0, 2)d=(−2,0,0,2).
  3. Square and add: d⋅d=4+0+0+4=8\mathbf{d} \cdot \mathbf{d} = 4 + 0 + 0 + 4 = 8d⋅d=4+0+0+4=8.
  4. Divide by n−1=3n - 1 = 3n−1=3: s2=8/3≈2.67s^2 = 8/3 \approx 2.67s2=8/3≈2.67.
  5. Square root: s=8/3≈1.63s = \sqrt{8/3} \approx 1.63s=8/3​≈1.63.

Two values are 2 from the mean and two are 0 from it; a typical distance of about 1.6 fits.

NumPy divides by nnn unless you write ddof=1; pandas uses n−1n - 1n−1 already. In this course, use n−1n - 1n−1 for data. For the bus routes in the hook, that gives 1.5 minutes (A) and 8.6 minutes (B).

Note · Why n − 1?

For a random sample, dividing by nnn makes the sample variance too small on average as an estimate of the population’s variance; dividing by n−1n - 1n−1 removes that bias. The SD is its square root — not itself exactly unbiased, but the standard choice. You will see this by simulation in Unit 7.

Use it · 6 min

Quartiles and the IQR

★ essentialSP

The SD is built on the mean, so it inherits the mean’s weakness: one extreme value moves it a lot. The robust alternative uses quartiles:

  • Q1Q_1Q1​: a quarter of the values lie below it;
  • Q2Q_2Q2​: the median;
  • Q3Q_3Q3​: three quarters lie below it.

The interquartile range IQR=Q3−Q1\text{IQR} = Q_3 - Q_1IQR=Q3​−Q1​ is the width of the middle half of the data.

Python

In describe(), the rows 25%, 50% and 75% are Q1Q_1Q1​, the median and Q3Q_3Q3​. (For very small data sets, textbooks use slightly different rules for quartiles; we use NumPy’s, which pandas shares.)
