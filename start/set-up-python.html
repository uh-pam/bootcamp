3  Set up Python

You can read the mathematics without running anything. But every unit ends with a short piece of code that checks the idea, and typing those in yourself — and breaking them, and fixing them — is worth a great deal.

This takes about half an hour, once.

If you would rather start reading now and set this up later, that is fine. Come back before P1.

3.1 1. Install Python

Download Python from python.org/downloads and install it. This course is written against Python 3.11; anything from 3.10 onwards will work.

On Windows, tick “Add python.exe to PATH” on the first installer screen. It is easy to miss and awkward to fix afterwards.

3.2 2. Make a folder and an environment

Open a terminal — Terminal on macOS or Linux, PowerShell on Windows — and run:

mkdir bootcamp
cd bootcamp
python -m venv .venv

That creates an isolated environment, so that anything you install here cannot disturb anything else on your machine. Activate it:

# macOS or Linux
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\activate

Your prompt should now start with (.venv). You need to do this each time you open a new terminal.

3.3 3. Install the packages

python -m pip install numpy==1.26.4 pandas==2.3.3 matplotlib==3.10.8 scipy==1.17.0 jupyterlab==4.5.3

The versions are pinned so that the numbers you get match the numbers printed in these notes exactly.

3.4 4. Check it worked

python -c "import sys, numpy, pandas; print(sys.version); print(numpy.__version__, pandas.__version__)"

You should see a 3.11 version string and then 1.26.4 2.3.3.

3.5 5. Get the data

Every example uses one small table. Download cohort.csv and background_meta.csv and put them in a data folder inside bootcamp.

Check that it loads:

python -c "import pandas as pd; print(pd.read_csv('data/cohort.csv').shape)"

You should see (240, 7).

3.6 When something goes wrong

It very often does, and the error message is usually more helpful than it looks.

Read the last line first. A Python error prints a long traceback, but the final line names the problem. ModuleNotFoundError: No module named 'pandas' means step 3 did not run in the environment that step 4 used — check that your prompt still shows (.venv).

python: command not found usually means the PATH box was missed during installation. Reinstalling and ticking it is faster than fixing it by hand.

Keep the whole error. If you need to ask someone, the exact text of the last line is the single most useful thing you can give them.

None of this is a test, and struggling with an install says nothing whatsoever about whether you can program. It is the least interesting part of the course and the only part where the computer, not the idea, is the obstacle.
