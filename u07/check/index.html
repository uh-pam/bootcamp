Choose7c

In a survey of 500 shoppers, 25 have no region. You want the mean spend in each region. Which is the best plan?

Drop the rows missing region when you compare by it: df.dropna(subset=["region"]), and say how many
Right: region is a category, so a gap there cannot be averaged or guessed. Drop those 25 rows for this comparison, and report it.
Fill the gaps with df["region"].mean()
region is text: it has no mean, and pandas raises a TypeError. Never fill a categorical column with a numeric mean.
Fill the gaps with the most common value of region
That invents a category for each gap and shifts that group's mean. A guess at a category is still a guess.
Drop the region column, since it has gaps
You need region to split the groups: without it there is no comparison.

A table of 300 houses has 90 gaps in floor_area, lost at random when two files were merged. You want to fit a model that uses every column, so each row needs a value. Which is the best plan?

Fill floor_area with its median, keep a flag column marking the 90 filled rows, and redo the analysis without them: report whether the answer changes
Right: with 30% of floor_area missing, no choice is free. Filling keeps the rows the next step needs; the flag shows which values are guesses, and the check without them shows whether those guesses change the answer.
Fill floor_area with its median, and say so: every row is kept
Saying so is not enough when 90 of 300 values (30%) are invented. They all sit at the centre, which shrinks the SD and weakens the relationships a model uses; without a flag column and a check without them, you cannot tell how much that changes the answer.
Fill floor_area with its median and keep a flag column marking the filled rows: the flag makes them as good as real measurements
The flag does not make a guess real: it is there so that you can redo the analysis without the filled rows and report whether the answer changes.
Fill the gaps with 0, so that no row is lost
0 is not a real value here: it drags the mean down and adds fake spread.
