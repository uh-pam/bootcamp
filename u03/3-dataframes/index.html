Idea · 5 min

Rows, columns and labels

★ essentialMP

A DataFrame is a table: each row is one record (a penguin), each column one variable (its mass, its island). On the left of every row sits its label, the index: 0 to 332 here. The label is not data; it is the row’s name tag.

One table, three ways

M Symbols

A table with nnn rows and ppp columns holds n×pn \times pn×p values. Write xijx_{ij}xij​ for the value in row iii, column jjj.

For the penguins, n=333n = 333n=333 and p=8p = 8p=8.

The numeric columns on their own form a matrix: df[cols].to_numpy() has shape (n,p)(n, p)(n,p), the kind of object you multiplied in Lesson 3.1.

Choose3c

You want a table with only the species and island columns, and write df["species", "island"]. What happens?

A KeyError
With one pair of brackets, pandas looks for a single column whose name is the pair ("species", "island"). There is none. Put the names in a list: df[["species", "island"]].
You get the two-column table
That needs the inner list: df[["species", "island"]]. The outer brackets select; the inner ones make the list of names.
You get the species column only
pandas never quietly ignores a name. It reads "species", "island" as one key, and that key does not exist.

Worked example · 6 min

Filter, then pick columns

★ essentialSP

In Unit 1 you filtered rows with a mask: df[mask] keeps the rows where the mask is True. Two new tools make filters shorter:

  • df["island"].isin(["Biscoe", "Dream"]) is True for rows whose island is one of the list. It replaces (df["island"] == "Biscoe") | (df["island"] == "Dream").
  • df.loc[rows, columns] filters the rows and picks the columns in one step. Before the comma: which rows. After it: which columns.

Use it · 4 min

Sort, then take the top rows

★ essentialP

sort_values("col") sorts the rows by one column, smallest first. Add ascending=False for largest first; .head(n) then keeps the top nnn. The hook used exactly this.

The labels travel with their rows: the heaviest penguin keeps its label, 163. So there are two ways to ask for “row 0”:

Picks rows byA slice [0:3] gives
.ilocposition, counting from 0, like a listpositions 0, 1, 2: the end is left out
.loclabel, the name tag on the leftlabels 0, 1, 2, 3: the end is included

To sort by two columns, pass a list: df.sort_values(["species", "body_mass_g"]).

Choose3c

This line should keep the male Adelie penguins, but it raises an error. What is the fix?

Use &, with round brackets round each comparison
and needs one True or False, but each comparison gives a whole column of them. Write df[(df["species"] == "Adelie") & (df["sex"] == "male")].
Change == to =
= stores a value in a variable; it cannot compare. Inside a filter you always need ==.
Use .iloc instead of plain brackets
.iloc picks rows by position, not by a condition. The problem is the word and.
Replace and with &, and change nothing else
Close, but Python does & before ==, so without brackets it tries "Adelie" & df["sex"] and fails. Bracket each comparison.

Choose all that apply3c

Which lines keep exactly the Adelie and Chinstrap penguins (every penguin that is one or the other)? Choose all that apply.

df[df["species"].isin(["Adelie", "Chinstrap"])]
isin is True when the species is one of the list.
df[(df["species"] == "Adelie") | (df["species"] == "Chinstrap")]
Each penguin needs to pass one test or the other, so | is right, with brackets round each comparison.
df[(df["species"] == "Adelie") & (df["species"] == "Chinstrap")]
No penguin is both species at once, so & keeps no rows. In everyday speech “Adelie and Chinstrap” means or in code.
df[df["species"] == "Adelie" | df["species"] == "Chinstrap"]
The right idea, but without brackets Python does | before == and raises a TypeError.

Wrap-up · 1 min

Wrap-up

You can now…

  • select one column (a Series) or several (a DataFrame), and rows by label with .loc or by position with .iloc;
  • filter rows with &, |, brackets and .isin, and pick columns in the same .loc[mask, cols];
  • sort by one or two columns and keep the top nnn rows.

Keep this pattern:

Taskpandas
size, names, typesdf.shape, df.columns, df.dtypes
one column (Series)df["a"]
several columns (DataFrame)df[["a", "b"]]
rows by position (end left out)df.iloc[0:5]
rows by label (end included)df.loc[0:5]
filter rowsdf[(cond1) & (cond2)] or df[df["a"].isin([...])]
filter and pick columnsdf.loc[mask, ["a", "b"]]
sort, then the top nnndf.sort_values("a", ascending=False).head(n)
numeric columns as a matrixdf[cols].to_numpy()
