Data Science Core Skills

Build your background before you arrive

Published

August 2026

Welcome. This is a self-study course in the mathematics, statistics and Python you will need for an MSc in Data Science. It is open, free, and designed to be worked through before your course begins.

You do not need to have done any of it to start your degree. It exists because students arrive from very different backgrounds — some have not seen calculus in a decade, some have never written a line of code, some have both and want to refresh — and because arriving with these ideas already familiar makes the first term substantially easier.

What is here

Thirty-five short units across three tracks.

Track Units Reading With practice
Python 11 68 pages ≈ 20.5 hours
Mathematics 12 60 pages ≈ 23.5 hours
Statistics 12 69 pages ≈ 23 hours

Python comes first, and that is deliberate. Every mathematics and statistics unit ends by checking its own claim in a few lines of code — a derivative against a numerical estimate, a confidence interval against a simulation. Those checks are the most useful part of each unit, and they are only useful if you can read them.

Every unit is built to the same shape and sized for one sitting: a few pages to read, a worked example, exercises with full solutions, a short piece of code that checks the idea, and five questions to test yourself. Nothing is hidden in an appendix, because there are no appendices.

Where to start

NoteThree things, in this order
  1. How to use this — five minutes. How the units work, how much to do at a time, and how to tell what you can skip.
  2. Set up Python — thirty minutes, once. You can read the mathematics without it, but you will get much more from every unit if the code runs on your own machine.
  3. The diagnostic — twenty minutes. Fifteen questions whose only purpose is to tell you which units you can skip.

How much time it takes

Working through everything takes roughly 65 to 70 hours. How you spread that is up to you, and the units do not expire:

  • Four weeks, most of a working week — the intensive route, if you have the summer free.
  • Ten weeks, an evening or two a week — the steady route, and the one most people take.
  • Only what the diagnostic flags — perfectly legitimate. If you last used matrices two years ago, refresh matrices and leave the rest.

Downloading it

Each track is also a PDF booklet, if you prefer to read away from a screen or work on paper. They contain exactly the same material as the site — the code, the figures, and the solutions in full rather than hidden behind a click.

Python 11 units installing Python to an analysis someone else can rerun
Mathematics 12 units rates of change to eigenvectors and the SVD
Statistics 12 units what question you are asking to how analyses go wrong

Three booklets rather than one volume, because a hundred pages on one subject is something you might read and four hundred on three is something you file away.

About the data

Every worked example uses one small table describing a fictional previous cohort: their prior background, hours of practice, and final scores. The data are invented. They describe no real student and no real cohort, and the script that generates them is included in the repository so you can see exactly how they were made.

Using one dataset throughout means you never have to learn a new context to follow an example — by the third unit you will know what the columns mean, and you can spend your attention on the idea instead.
