Expectation and variance

★ essentialMSP

A random variable XXX is a number decided by chance: your gain on a ticket, the children in a household. A discrete one has separate values kkk. Its distribution lists each value with its probability P(X=k)P(X = k)P(X=k); the probabilities add up to 1.

The expectation E[X]E[X]E[X] is the probability-weighted mean of the values, the long-run average. Its variance is the weighted mean squared distance from μ=E[X]\mu = E[X]μ=E[X]:

E[X]=∑kk P(X=k),Var(X)=∑k(k−μ)2 P(X=k),σ=Var(X)E[X] = \sum_k k\,P(X = k), \qquad \mathrm{Var}(X) = \sum_k (k - \mu)^2\,P(X = k), \qquad \sigma = \sqrt{\mathrm{Var}(X)}E[X]=k∑​kP(X=k),Var(X)=k∑​(k−μ)2P(X=k),σ=Var(X)​

For the raffle, E[X]=(−2)(0.89)+8(0.10)+48(0.01)=−0.50E[X] = (-2)(0.89) + 8(0.10) + 48(0.01) = -0.50E[X]=(−2)(0.89)+8(0.10)+48(0.01)=−0.50: no single ticket loses exactly 50p. E[X]E[X]E[X] is an average, not a value XXX must take.

There is no n−1n - 1n−1 here. The weights are exact probabilities, not a sample of data.

Counting events: the Poisson

★ essentialMSP

Some counts have no fixed maximum: calls per hour, typos per page, goals per match. If events happen independently at a steady average rate λ\lambdaλ per interval, the count in one interval is X∼Poisson(λ)X \sim \mathrm{Poisson}(\lambda)X∼Poisson(λ):

P(X=k)=λke−λk!,E[X]=Var(X)=λP(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \qquad E[X] = \mathrm{Var}(X) = \lambdaP(X=k)=k!λke−λ​,E[X]=Var(X)=λ
Worked example: a help line with 3 calls per hour
  1. One hour, so X∼Poisson(3)X \sim \mathrm{Poisson}(3)X∼Poisson(3).
  2. P(X=0)=30e−3/0!=e−3=0.0498P(X = 0) = 3^0 e^{-3}/0! = e^{-3} = 0.0498P(X=0)=30e−3/0!=e−3=0.0498, because 30=13^0 = 130=1 and 0!=10! = 10!=1.
  3. P(X=1)=3e−3/1!=0.1494P(X = 1) = 3 e^{-3}/1! = 0.1494P(X=1)=3e−3/1!=0.1494.
  4. At least 2 is everything except 0 and 1: P(X≥2)=1−0.0498−0.1494=0.8009P(X \ge 2) = 1 - 0.0498 - 0.1494 = 0.8009P(X≥2)=1−0.0498−0.1494=0.8009.
Python

The simulated shares, 0.0492 and 0.8005, match; the mean and variance, 3.01 and 3.05, are both close to λ\lambdaλ.

The rate must match the interval. 3 calls per hour is 1.5 per half hour, so a half hour has X∼Poisson(1.5)X \sim \mathrm{Poisson}(1.5)X∼Poisson(1.5).
