Idea · 6 min

Rows, columns and types

★ essentialSP

Three commands tell you what a new dataset looks like: df.shape gives (rows, columns), df.columns the column names and df.dtypes the kind of values in each column. Add print(df.shape) and print(df.dtypes) to the cell above and run it again.

Each row is one penguin, one record: an element of the set UUU from Lesson 1.1. Each column is a variable. Variables come in two main types:

TypeValues areIn the penguin dataSummarise with
Categorical, nominallabels with no orderspecies, island, sexcounts, bar chart
Categorical, ordinallabels with a natural ordernone here; e.g. a survey answer “disagree / neutral / agree”counts, in order
Numericalmeasurements or counts, where arithmetic makes sensebill_length_mm, flipper_length_mm, body_mass_gmean, histogram (Unit 2)

df.dtypes is a good first clue. Text columns show as object (or str in newer pandas) and are almost always categorical. Numbers show as int64 or float64, but a number can still be a label, such as a postcode or a customer ID. Ask: would an average make sense? An average postcode means nothing. year is a special case: as a date it is a numerical time variable, but here it only names the three field seasons, 2007 to 2009, so you can also count it like a category.

Categorical, ordinal
The numbers are only codes for answers, but the answers do have a natural order.
Numerical
The numbers are codes. “Neutral minus disagree” has no meaning, and the average of an agree and a disagree is not a neutral answer.
Categorical, nominal
Categorical, yes, but these answers have a natural order: disagree, neutral, agree. That makes it ordinal.

A frequency table

A frequency table counts how many records fall in each category. Each count is the size of a set.

P Code
Worked example: species counts and proportions
Python

A proportion, or relative frequency, lets you compare groups of different sizes: 0.438 means 43.8% of the penguins in this data are Adelie. pandas has a shortcut for the proportions: df["species"].value_counts(normalize=True).

A bar chart draws one bar per category, with height equal to its count: the standard chart for a categorical variable. The bars stand apart, because the categories are separate (a histogram of a numerical variable has touching bars; that is Unit 2). value_counts() sorts the bars from tallest to shortest; for ordinal categories, keep their natural order with .sort_index().

That turns the fraction upside down. The 0.489 is Biscoe’s share of this data, not the data’s share of Biscoe.

The table describes these 333 penguins only. Whether it holds for all penguins is a question about samples, which comes in Unit 7.
