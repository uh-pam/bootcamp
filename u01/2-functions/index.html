P Code

The parts of a Python function:

  • def, then the name, then the parameters (the inputs) in brackets, then a colon.
  • The body is indented by four spaces.
  • A docstring in triple quotes says what the function does. help(f) shows it.
  • return sends the output back to whoever called the function.

Domain and range. The set of inputs a function accepts is its domain. The set of outputs it can give is its range. For h(x)=x2h(x) = x^2h(x)=x2 the domain is every number, and the range is h(x)≥0h(x) \ge 0h(x)≥0, because a square is never negative. For g(x)=1xg(x) = \frac{1}{x}g(x)=x1​, the input 000 is not in the domain: in Python, 1 / 0 stops with a ZeroDivisionError.

print is not return

★ essentialMP

A classic mix-up. Predict first, then run the same code in the cell below.

Predict1c

Both functions below show 10 on screen, but only one gives it back. What does the last line print?

10 10
double_print shows 10 on screen but gives nothing back, so a holds nothing.
None 10
print only shows a value; it does not hand it back. A function with no return gives back None, Python’s “nothing”.
10 None
The other way round: it is the function without return that gives back None.
An error
No error: a function without return is allowed. It quietly gives back None, which is why this bug is easy to miss.
Python

The first line of output, 10, comes from inside double_print. Use print to look at a value; use return when you want to store or reuse it.
