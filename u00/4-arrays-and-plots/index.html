Arrays and slices

★ essentialMP

An array is like a list of numbers that understands arithmetic. An operation on the array happens to every value at once, with no loop, and NumPy functions such as np.sqrt work on whole arrays too.

Arrays count positions from 0, like lists. A slice a[start:stop:step] picks out a run of values. The stop position is not included, and a part you leave out takes its default: the start, the end, or a step of 1. With a = np.array([10, 20, 30, 40, 50, 60, 70, 80]):

SliceMeansGives
a[1:4]positions 1, 2, 3 (not 4)[20 30 40]
a[:3]the first 3[10 20 30]
a[5:]from position 5 to the end[60 70 80]
a[::2]every 2nd value[10 30 50 70]
a[::-1]backwards[80 70 … 10]

Solution

Choose0d

Which line selects the body mass column?

df["body_mass_g"]
The column name goes in square brackets and quotes, spelled exactly as in the file.
df[body_mass_g]
Without quotes, Python looks for a variable called body_mass_g and gives a NameError. Column names are text.
df["Body mass"]
Column names must match exactly, capitals and underscores included. This gives a KeyError.
df("body_mass_g")
Round brackets call a function. To select a column, use square brackets.
