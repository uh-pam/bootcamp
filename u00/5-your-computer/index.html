Worked example · 8 min

Install Anaconda

★ essentialP

Go to anaconda.com/download and download the current Anaconda Distribution installer for your system. The page may ask for your email address; there is usually a link to skip that. Use the installer’s own Python version: do not look for a newer one.

You need a few gigabytes of free disk space. The download and install take another 10–20 minutes, on top of this lesson’s 30: start them, then take a break while they run.

Windows

Section titled “Windows”
  1. Download the 64-bit graphical installer (.exe) and run it.
  2. Accept the licence. For installation type, choose Just Me (recommended).
  3. Keep the suggested folder. If your Windows user name contains spaces or accents and the installer warns you, choose a simple folder such as C:\anaconda3.
  4. On “Advanced options”, leave Add Anaconda to my PATH unticked: it can clash with other programs. Keep the other defaults.
  5. When it finishes, open the Start menu. You now have Anaconda Navigator and Anaconda Prompt.

macOS

Section titled “macOS”
  1. Check your chip: Apple menu → About This Mac. “Chip: Apple M1” (or M2, M3, M4…) means you need the Apple silicon installer. “Processor: Intel” means the Intel installer.
  2. Download the matching graphical installer (.pkg) and open it.
  3. Accept the licence and choose Install for me only.
  4. When it finishes, Anaconda-Navigator is in your Applications folder. A new Terminal window shows (base) at the start of the prompt.

Linux

Section titled “Linux”
  1. Download the installer (.sh) for your processor (usually x86_64).
  2. In a terminal, run it with bash, for example bash ~/Downloads/Anaconda3-*-Linux-x86_64.sh.
  3. Press Enter to read the licence, type yes to accept, keep the suggested location, and answer yes when asked to initialise conda.
  4. Close the terminal and open a new one. The prompt now starts with (base).

Check it. Open Anaconda Prompt (Windows) or Terminal (macOS, Linux) and type python --version. You should see Python 3 and a version number.

Choose0a

Your MacBook’s “About This Mac” says Chip: Apple M2. Which installer do you download?

The Apple silicon installer
M1, M2, M3 and later chips are Apple silicon. The matching installer runs at full speed.
The Intel installer
That is for Macs whose “About This Mac” says “Processor: Intel”. On an M-series Mac it runs slowly through translation, and some packages misbehave.
Either; they are the same
They are built for different processors. Pick the one that matches your chip.

Choose0a

The Windows installer offers Add Anaconda to my PATH environment variable. What should you do?

Leave it unticked, and use Anaconda Prompt or Navigator
Anaconda’s own shortcuts find Python without it. Adding it to PATH can clash with other software.
Tick it, so Python works everywhere
Anaconda advises against it: it can break other programs that use their own Python. Anaconda Prompt already has everything set up.

Idea · 6 min

Open Jupyter and Spyder

★ essentialP

Jupyter

Section titled “Jupyter”
  1. Open Anaconda Navigator and click Launch under JupyterLab. Or, in Anaconda Prompt (Windows) or Terminal (macOS, Linux), type jupyter lab and press Enter.
  2. JupyterLab opens in your web browser. On the left is a file browser, starting in your home folder. Jupyter can only see files inside the folder it started in.
  3. Click the New Folder button, name the folder bootcamp, and double-click to open it.
  4. In the Launcher, click Notebook (Python 3). Type 2 + 3 in the first cell and press Shift+Enter.
  5. When you are done, save (Ctrl+S, or Cmd+S on a Mac) and choose File → Shut Down. Closing the browser tab alone leaves Jupyter running.

Your modules may say “Jupyter Notebook” rather than “JupyterLab”. Both open the same .ipynb files; Navigator has both.

Spyder

Section titled “Spyder”
  1. In Anaconda Navigator, click Launch under Spyder, or type spyder in Anaconda Prompt or Terminal.
  2. The editor is on the left: write a script there and save it as a .py file. The console is at the bottom right, and plots appear in the Plots pane at the top right.
  3. Press F5 (or the green ▶) to run the whole file, or F9 to run only the current line or selection.
Choose0a

Navigator is slow to open. What else starts JupyterLab?

Type jupyter lab in Anaconda Prompt (Windows) or Terminal (macOS, Linux)
That starts the same JupyterLab, in your browser, often faster than Navigator.
Double-click an .ipynb file
A notebook file is not a program; double-clicking usually opens it as text or asks what to do. Start Jupyter first, then open the file inside it.
Type jupyter lab in a Python cell on this website
This site runs Python inside your browser and cannot start programs on your computer.

Your browser saved the notebook as hello-bootcamp.ipynb.txt, and Jupyter will not open it as a notebook. What do you do?

Rename it to hello-bootcamp.ipynb, removing the .txt
The content is fine; only the name is wrong. Jupyter recognises notebooks by the .ipynb ending.
Copy its text into a new notebook cell

When something goes wrong

★ essentialP

Most set-up problems are one of these. Find your symptom.

SymptomWhyFix
FileNotFoundError: ... 'penguins.csv'Python looks for files in its working folder: in Jupyter, the folder the notebook is in.Put the CSV in the same folder as the notebook (or script), or give the full path, e.g. pd.read_csv("C:/Users/you/bootcamp/penguins.csv").
You cannot find your Documents or Desktop in JupyterJupyter only shows the folder it started in and the folders inside it. On Windows, Documents may sit inside a OneDrive folder.Start Jupyter from Navigator (it starts in your home folder) and look inside OneDrive; or keep a bootcamp folder in your home folder.
A cell shows [*] for ages, and Ctrl+C does nothingIn a notebook, Ctrl+C means copy, not “stop”.Press the ■ button (interrupt the kernel), or Kernel → Interrupt Kernel. If still stuck, Kernel → Restart Kernel.
Windows PowerShell: “running scripts is disabled on this system” when activating an environmentPowerShell’s execution policy blocks activation scripts.Use Anaconda Prompt from the Start menu instead. You do not need to change any security settings.
ModuleNotFoundError: No module named 'numpy' when you type python in a normal terminalThat is a different Python on your computer, without Anaconda’s packages.Use Anaconda Prompt (Windows), a new Terminal showing (base) (macOS, Linux), or Navigator.
macOS: CERTIFICATE_VERIFY_FAILED when reading a CSV from a web addressThe Python from python.org does not use the Mac’s security certificates until you install them.Use Anaconda’s Python. If you must use python.org’s, run Install Certificates.command in its folder in Applications.
pip install numpy fails, or tries to build it for minutesA brand-new Python version, before packages are ready for it.Use Anaconda’s default Python; it comes with every package you need.

Lesson check · 2 min

Set-up check

★ essentialP

Three situations you are likely to meet. Take as many tries as you need.

Choose0a

Jupyter says FileNotFoundError: [Errno 2] No such file or directory: 'penguins.csv'. What should you do?

Put penguins.csv in the same folder as the notebook, or use its full path
The notebook looks in its own folder. Once the file is there, and the name is spelled exactly, pd.read_csv("penguins.csv") finds it.
Reinstall Anaconda
Anaconda works: the error comes from pandas, which is running fine. The file is just not where Python is looking.
Run pip install penguins
A data file is not a package. Move the file next to the notebook instead.

Choose0a

A cell has shown [*] for five minutes, and pressing Ctrl+C did nothing. What next?

Press ■ (interrupt the kernel), or choose Kernel → Interrupt Kernel
That stops the running cell. Ctrl+C in a notebook copies text instead.
Close the browser tab
The code keeps running on your computer after the tab closes. Interrupt the kernel instead.
Wait: it will finish eventually
It may be stuck in a loop that never ends. Interrupt it, then look at the code.

Choose0a

In Windows PowerShell you see “running scripts is disabled on this system”. What is the simplest fix?

Open Anaconda Prompt from the Start menu and work there
Anaconda Prompt is already set up for Python and conda, with no security settings to change.
Install another Python from python.org
A second Python adds confusion and does not change PowerShell’s rules. Use Anaconda Prompt.
Turn off Windows security
Never needed. Anaconda Prompt avoids the problem entirely.
