Hook · 4 min

Running code here

★ essentialP

If you have ever typed =B2*1.2 into a spreadsheet, you have written code: an instruction a computer carries out. Python is the same idea with more room.

Predict first
Before you run anything: what do you think Python gives for 7 / 2?
Your answer0a

Type your prediction, then check it in the cell below.

Some languages drop the remainder, but in Python / is ordinary division: 7÷2=3.57 \div 2 = 3.57÷2=3.5.

Every grey box with a ▶ Run button is a Python cell. Press Run, or click inside the cell and press Shift+Enter. The first run takes a few seconds while Python loads.

Python

Two things appeared: the text from print(...), and 3.5. A cell always shows the value of its last line, so you can check a result without print.

Errors are normal, and they are there to help. Change print to prnt in the cell and run it again. Python names the problem (NameError: it does not know the word prnt) and the line. Fix the spelling and run it once more; Reset code puts a cell back as it was.

Numbers and arithmetic

★ essentialMP

Python works as a calculator. The symbols differ a little from the ones on paper:

Python follows the same order of operations as maths: brackets first, then powers (**), then *, / and //, then + and -. When in doubt, add brackets. Try your own sums in the cell above.

Your answer0b

What does Python give for 2 + 3 * 4 ** 2? Work it out, then check in the cell above.

You went left to right. Powers come first: 4 ** 2 is 16, then 3 * 16 is 48, then + 2.
You did 3 * 4 before the power. ** comes first: 4 ** 2 is 16, and 3 * 16 is 48.

Powers first, then multiplication, then addition.
4 ** 2 is 16.
Solution
4 ** 2 is 16; 3 * 16 is 48; 2 + 48 is 50.
Choose0b

Which line works out 727^272?

7 ** 2
In Python, ** is “to the power of”. It gives 49.
7 ^ 2
A common trap: ^ means something else in Python (a bitwise operation) and gives 5, with no error. Use **.
7 * 2
That is 7×2=147 \times 2 = 147×2=14. A power multiplies 7 by itself: 7 ** 2.

★ essentialMP

A variable is a name for a value. You create one with =:

One idea, three ways

In Python, = is not “equals”. It means: work out the right-hand side, then store the result under the name on the left. So x = x + 1 is fine: it takes the old x, adds 1 and stores the new value. Text goes in quotes and is called a string: species = "Gentoo".

Lists and built-in functions

★ essentialP

A list holds several values in order, inside square brackets. Each value has a position, and Python counts positions from 0. A function such as len or sum takes values in brackets and gives back a result.

Lesson check · 4 min

Lesson check

★ essentialMP

Four questions on this lesson. Take as many tries as you need.

Choose0a

You run a cell and see NameError: name 'totl' is not defined. What is the most likely fix?

Correct the spelling of totl, or run the cell that creates it first
A NameError means Python has never been given that name: a typo, or a variable created in a cell you have not run yet.
Restart the computer
Nothing is broken. Python is telling you exactly which name it does not know.
Put quotes round totl
Quotes would turn it into the text “totl”, not the variable’s value. The name itself needs fixing.

Your answer0b

What does Python give for (2 + 3) * 4 ** 2 // 10?

// divides: (2 + 3) * 16 is 80, and 80 // 10 is 8.
Brackets first, then the power: (2 + 3) is 5 and 4 ** 2 is 16.
Solution
(2 + 3) is 5; 4 ** 2 is 16; 5 * 16 is 80; 80 // 10 is 8.

Choose0b

x = [5, 10, 15]. What happens with x[3]?

An IndexError
Three values sit at positions 0, 1 and 2. There is no position 3.
15
15 is at position 2. Counting from 0, the last position of a three-item list is 2.
5
Python does not wrap around to the start. Asking for a missing position is an error.

Your answer0b

marks = [62, 71, 58, 80, 67]. What does sum(marks) / len(marks) give?

That is sum(marks), the total. Divide it by len(marks), the number of marks.
That is len(marks), how many marks there are. The line divides the total by it.
sum(marks) is 338 and len(marks) is 5.
Solution
sum(marks) is 62+71+58+80+67=33862 + 71 + 58 + 80 + 67 = 33862+71+58+80+67=338, len(marks) is 5, and 338÷5=67.6338 \div 5 = 67.6338÷5=67.6: the mean mark.
